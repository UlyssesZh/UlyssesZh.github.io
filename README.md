# UlyssesZh.github.io

UlyssesZhan's blog!

## Build

Install Ruby, Node.js, GHC, and Cabal. Then run:

```shell
bundle install
bundle exec rake build
```

## Development

Use `bundle exec rake serve` to serve the site locally.
For a faster experience but limited features, use `bundle exec rake serve_i`.
