# UlyssesZh.github.io

UlyssesZhan's blog!

## Build

Install Ruby, Node.js, GHC, and Cabal. Then run:

```shell
bundle install
bundle exec rake build_libs
bundle exec jekyll build
```

`rake build_libs` builds the Haskell `pandoc-bridge` shared library and the `katex-bridge` JavaScript bundle.

## Development

Use `rake` to serve the site locally.
For a faster experience but limited features, use `rake serve_i`.
